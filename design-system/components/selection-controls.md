# Selection Controls

## Checkbox

복수 선택에 사용합니다. F-02 Portfolio Scope가 대표 사례입니다.

- Unselected / Selected / Disabled 상태
- Control과 label 전체 row를 44px 이상 touch target으로 사용
- 선택 여부를 색상만으로 전달하지 않고 check icon을 함께 표시
- 적용 전 선택은 draft state

F-02는 최소 1개 선택이 필요합니다. 마지막 항목의 해제는 허용하지만 0개일 때 Primary CTA를 disabled 처리합니다.

## Radio

단일 선택에 사용합니다.

- Currency Dropdown
- Sort option
- 서로 배타적인 설정

## Inline Disclosure

F-06의 `포트폴리오별로 보기`는 Navigation이 아닌 inline expand/collapse입니다.

- Chevron 사용 금지
- Default/Selected check icon 사용
- Expanded 상태에서 같은 화면 아래에 Portfolio breakdown 표시
